## Data Source

This project uses **[GH Archive](https://www.gharchive.org/)**, a public archive of GitHub events, for this course assignment. Raw hourly files are downloaded from `https://data.gharchive.org/` and passed through the instructor-provided `scripts/preprocess.py`, including its cohort filtering and anonymization. Models read only the resulting eight tables. No GitHub API activity data, additional event types, or external profile data are used.

Keep raw archives and generated tables local. Do not combine the former instructor-supplied tables with the revised anonymized tables: their identifiers and preprocessing differ. The course's [README](https://github.com/nycubigdata-2026fall/BigData2026-Assignment2/blob/main/README.md) and [schema](https://github.com/nycubigdata-2026fall/BigData2026-Assignment2/blob/main/SCHEMA.md) describe the current format.

## Model and temporal rules

The frozen primary policy is **H2/P021** (`h2_p021`): six histogram gradient boosting classifiers on 59 historical features, blended equally by rank with exponentially decayed seven-day activity scores. For each activity, predict the same number of positives as seven-day persistence on the requested roster; break ties by ascending `UserID`.

- Features use rows visible strictly before **C = prediction origin − 4 hours**.
- Training labels use observations available before **A = prediction origin − 3 hours**. No prediction-week labels are loaded in submission mode.
- Training uses daily origins on the 16:00 UTC grid satisfying `s >= origin − 63 days` and `s + 7 days <= A`: 56 origins for the official prediction time.
- Training weights decay with a two-week half-life. Random state is fixed at 42.
- Visibility is `first_seen_at` for PRs, issues and reviews, and `created_at` for comments and pushes. Later-known status fields are excluded.
- Stable user identity is `Users.github_user_id`; internal foreign keys are used only within one preprocessing run.

The same entry point also supports frozen `h2wpca_p021` and `h2dfs_p021` variants (PCA/logistic regression, with synthesized repository features for DFS), and `persist7`. They are explicit alternatives; changing the policy changes the output and must be recorded.

## Prepare the data

Download the UTC hours needed for the selected training/inference period from GH Archive, using the commands on its website. Filenames are `YYYY-MM-DD-H.json.gz`. The earliest population window for the final origin starts at **2026-06-07 12:00 UTC**; the final feature cutoff is **2026-11-21 12:00 UTC**. Downloading a wider historical interval is allowed; the feature and label builders apply their own time filters.

For example, in Bash, download May through October and November 1–20, then the first twelve November 21 hours:

```bash
mkdir -p data/raw
for month in 05 06 07 08 09 10; do
  for day in $(seq -w 1 31); do
    wget -nc -P data/raw https://data.gharchive.org/2026-${month}-${day}-{0..23}.json.gz
  done
done
wget -nc -P data/raw https://data.gharchive.org/2026-11-{01..20}-{0..23}.json.gz
wget -nc -P data/raw https://data.gharchive.org/2026-11-21-{0..11}.json.gz
```

Invalid calendar dates and unavailable archive hours return HTTP errors. Record missing hours; an absent event type is not proof that users were inactive. These are large public archives. The November 21 files become available only after their corresponding hours have finished; do not treat this future-data command as executable in full before then.

Run the instructor's preprocessor on the downloaded hours:

```powershell
python data/course/scripts/preprocess.py --raw data/raw --out data/final_20261121
```

This creates `data/final_20261121/db/` with `Users`, `Repositories`, `PullRequests`, `Issues`, `IssueComments`, `PRReviews`, `PRReviewComments` and `Pushes` Parquet files. Use a fresh output directory for a changed input archive. Do not edit the generated tables.

## Results and evidence

The latest revised-data replay covers **13,711 user-weeks** across three mature October windows and the three activities with consistent archive coverage (`open_pr`, `open_issue`, `pr_review`).
